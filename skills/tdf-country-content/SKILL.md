# TDF country content

Снимок практики на 2026-10-30: измерения по 10 деревьям репозитория (POR, SOV, SYR, ARM, ISR, POL, KAZ, BLR, HUN, SLO), правила скила `md-hoi4-country-content` и решения команды. Это рекомендации, а не спецификация. Если файлы, wiki или игра противоречат этому скилу - верить им и сказать об этом. Числа с пометкой "ориентир" не измерены, а предложены.

В репозитории лежит только срез мода (`mdredux/`). Базового мода нет: GENERIC-идеи, общие scripted effects и события чужих namespace (`CSTO.1`, `union_state.22`) проверить нельзя. Такие ссылки называть "вне репозитория", а не "багом".

## 1. Философия: фокус даёт инструмент

Позиция команды: фокус даёт ИНСТРУМЕНТ, который расширяет контент и даёт стране уникальную механику. Лучше меньше фокусов, но каждый с механикой, чем длинное дерево из "+числа" (антипримеры по словам команды - Нидерланды и Чехия; их нет в этом репозитории, поэтому здесь они не оцениваются). Механик в моде много, взаимодействие с ними должно быть простым. Мы не Political Power Dawn: контент держится на грани "интересно" и "легко понять".

Тест на каждый фокус (если честного "да" нет - слить, удалить или сделать мостом):
1. Какой инструмент остаётся у игрока? (таблица ниже)
2. Что изменится в геймплее, если фокуса не будет?
3. Если убрать из награды казну, PP, стабильность, бонусы технологий и постройки - что останется?
4. Описание объясняет реальную награду, а tooltip читается за 10 секунд?

| Инструмент (засчитывается) | Пример в репозитории |
|---|---|
| Решение или категория решений | Россия: `SOV_kremlin_category` (около 41 решения); Беларусь (6 категорий), Израиль (7), Венгрия (5) |
| Событие с реальным выбором, цепочка предложение - ответ | Россия: `sov_economic.2` (суд над Ходорковским) |
| Дух-ключ: открывает решения (`visible = { has_idea = X }`) | Россия: механика РЖД (`SOV_rjd_idea`); рядом механики Роскосмоса, Вагнера, Стабфонда |
| Дух-хаб: состояние страны из ступенчатых скрытых духов, видимых через scripted loc | Португалия: `POR_portuguese_economy_idea` |
| Флаг или переменная, которую читает другой контент | Израиль: 149 чтений флагов в решениях |
| MIO, доктрина, уникальный вариант техники | Казахстан: 10 `mio:` в фокусах |
| Смена партии, коалиции, фракции, закона | `add_relative_party_popularity`, `change_ruling_party_effect` |
| Дипломатический шаг с последствиями | гарантии, торговые соглашения, вассализация |

Не инструмент (приправа, а не причина фокуса): казна, PP, стабильность, `add_tech_bonus`, постройки, пачка статичных модификаторов. Приправа допустима внутри инструментального фокуса.

Ориентир (предложение, не измерено): ветка 6-15 фокусов, не более двух "мостов" без инструмента подряд, в дереве не меньше двух третей фокусов с инструментом. Сейчас, по грубой автометрике, доля фокусов с инструментом в репозитории 22-55% (см. `docs/research/2026-10-tdf-trees-audit.md`).

## 2. Как устроена страна в ТДФ

Коротко (подробности и цифры: `references/country-structure.md`):
- Дерево - 4-8 столпов (shortcut): политика по партийным маршрутам, экономика, армия, дипломатия и 1-2 уникальных столпа страны.
- Политика - самая большая часть: у каждой значимой субидеологии свой маршрут и свой набор фокусов.
- Гейты везде: у 73-89% фокусов есть `available` (партия, мнение, партнёр, предыдущий фокус), а не даты.
- Страна работает на системах мода: казна, влияние, партии и коалиции, внутренние фракции, законы, ЕС и НАТО, компании, энергетика.
- Механика страны живёт в духах, решениях и событиях, а не в самом фокусе: фокус открывает дверь.

## 3. Рабочий цикл на один фокус

1. Открыть код фокуса, его локализацию и всё, что он трогает (идеи, события, решения, scripted loc).
2. Прочитать фактический `completion_reward`. Всё, что описано в тексте, должно быть в награде, и наоборот: награда должна быть объяснена в тексте.
3. Проверить: `log` = id фокуса, prerequisites существуют, `available` выполнимо, DLC-охрана, нет двойного бонуса, идея существует, скрытые духи показываются.
4. Написать описание (`references/focus-loc.md`), числа сверить с медианами (`skills/md-hoi4-country-content/references/balance.md`).
5. Запустить `scripts/tdf_audit.py` и убедиться, что ошибок не прибавилось.
6. Отдать только изменённые строки; всё больше ~30 строк положить в файл. Явно перечислить непроверенное. Проверка текста репозитория - не тест в игре: не заявлять, что мод запускали.

## 4. Что соблюдать

Фокусы (`references/focus-design.md`):
- Один id = один фокус; `log` в `completion_reward` с тем же id (формат репозитория: `log = "[GetDateText]: [Root.GetName]: Focus ID"`, у ARM и ISR - `focus ID executed`).
- Альтернативы делать альтернативами (`mutually_exclusive`, OR-prerequisite), а не обязательной цепочкой. Капстоун достижим без посторонних веток.
- Не называть "созданием" то, что уже существует: моделировать расширение, модернизацию, локализацию.
- Не копировать чужую страну: чужие префиксы в идеях и флагах (`POL_` в Словакии) - баг.

Описания фокусов - по Португалии (`references/focus-loc.md`): факт, затем "мы сделаем", затем короткое последствие; 200-280 знаков, жёсткие границы 150-340; без запретных слов.

События - по России (`references/event-loc.md`): заголовок как заголовок новости, описание от лица получателя, реплики-опции с характером, никаких "Nice/Good/Excellent". Событие только там, где есть выбор или настоящий флейвор.

Нацдухи (`references/national-spirits.md`): один дух - один профиль, 3-5 модификаторов (капстоун до 6), не повторять бонус в фокусе, духе и событии, скрытый дух обязан где-то показываться.

Баланс модификаторов, частые ошибки и итоговый чек-лист: `references/balance-and-pitfalls.md`.

Формат файлов: tabs в `.txt`, yml в UTF-8 с BOM, заголовок `l_english:`, CRLF не трогать, ключи уникальны. Перед переименованием фокуса найти все ссылки по репозиторию (дерево, loc, prerequisites, `available`, события, идеи, scripted loc).

## 5. Проверка

```
python3 -I skills/tdf-country-content/scripts/tdf_audit.py .                # таблица по странам
python3 -I skills/tdf-country-content/scripts/tdf_audit.py . --details KAZ  # списки id по проверкам
```

Скрипт ловит: дубли id и ключей loc, `log` не равен id, отсутствующие prerequisites, пропущенные title и desc, длины, запретные фразы, чужие префиксы, события вне репозитория, generic-подписи опций, табы и баланс скобок. Он не запускает игру и не видит базовый мод.

## 6. Известные проблемы репозитория (на 2026-10-30)

Подробности и списки: `docs/research/2026-10-tdf-trees-audit.md`.
- Казахстан: нет `_desc` у 73 из 370 фокусов, 25 дублей ключей loc, 824 строки с пробелами вместо табов.
- Словакия и Венгрия: копипаста (`log` не равен id у 37 из 180 и 44 из 326 фокусов; в Словакии идеи с префиксом `POL_`).
- Польша: у 13 фокусов (в основном космос и спутники) нет ни title, ни desc среди найденных ключей; 73 описания с запретными словами.
- Generic-подписи опций событий: Израиль, Армения, Россия, Казахстан (`Decline the proposal` x59).
- Старый MD-скил восстановлен в `skills/md-hoi4-country-content/` (корневой `MD_SKILL.md` был повреждён и заменён ссылкой); `.skill`-пакет в корне устарел и не содержит раздел про Казахстан.
