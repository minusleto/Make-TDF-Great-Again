# Баланс модификаторов и частые ошибки

Источник: практика по дереву Казахстана (документ Qwen), перепроверенная по репозиторию 2026-10-30. Что подтвердилось, помечено; что нет - сказано. Медианы по четырём странам: `skills/md-hoi4-country-content/references/balance.md` (в `.skill`-пакете).

## 1. Правила баланса (взято)

| Правило | Проверка |
|---|---|
| Ранний фокус не сильнее позднего в той же линии (`KAZ_foreign_equipment` не сильнее `KAZ_SARP_modules`) | логика, в коде не измерялось |
| `coordination_bonus` до 0.10 для фокуса за 5 | совпадает с медианой 0.09-0.10, максимум 0.20 в `balance.md` |
| Не дублировать модификатор между духами одной линии (`training_time_army_factor` в двух духах) | = правило "один дух - один профиль" |
| `army_speed_factor` не лепить в ремонтные и лицензионные фокусы | тематичность |
| Не выдумывать модификатор: сверить по ideas или wiki | `equipment_upgrade_cost_factor`, `reliability_factor`, `intelligence_from_cipher_decript_factor` не найдены ни в идеях репозитория, ни в wiki; остальные из его списка используются в идеях (`land_mastery_gain_factor` 3, `no_supply_grace` 4, `initiative_factor` 5, `special_forces_cap` 15). В wiki описаны только модификаторы MDC, ванильные там не перечислены |
| Цепочка штрафов убывает ступенями, последняя ступень близка к нулю, затем плюсовой профиль | подтверждено: `KAZ_outdated_army_idea` -20% атака и защита, -15% орг, -10% скорость, -10% mastery -> ступени 1-3 -> `KAZ_professional_army_idea` +5% и +10% mastery |
| Слишком сильно: `army_armor_attack_factor 0.07` + защита + скорость разом; `planning_speed 0.15` + `max_planning_factor 0.12` + `recon_factor 0.17` + `coordination_bonus 0.20` в одном духе | ориентир |

Заметка: бонусы к технологиям в Казахстане 0.5-0.75 выше медианы 0.25-0.35 (`KAZ_arsenal_update` 0.75, `KAZ_new_military_uniform` 0.75), сверять с `balance.md`.

## 2. Скриптованная локализация скрытых духов (подтверждает наш шаблон)

Скрытый дух показывается через `defined_text` и сводный tooltip (`KAZ_army_tt`, у Португалии `POR_portuguese_economy_tt`). Правила:
- В сводный tooltip только скрытые духи; видимые национальные духи игрок и так видит.
- Использовать `$modifier$`, если токен есть в локализации; если токен не работает - писать вручную.
- `equipment_bonus` выводить одной строкой, а не по каждому шасси.
- Фокус с таким духом ставит `custom_effect_tooltip = <TAG>_army_tt`.

## 3. Частые ошибки

| Ошибка | Пример | Решение |
|---|---|---|
| `swap_ideas` на ту же идею | `remove_idea = X` + `add_idea = X` | скрипт `tdf_audit.py` ловит (`swap_same_idea`); сейчас 1 случай: `SOV_faith_in_commander_in_chief` (`the_military` -> `the_military`), проверить намеренность |
| Дубль `swap_ideas` в двух фокусах (оба делают `_2 -> _3`) | `KAZ_reform_military_districts` и `KAZ_creation_of_sso` | вручную: искать одинаковые пары; автопроверка шумит на законах и фракциях (`landowners -> the_military` легально повторяется), поэтому в скрипт не включена |
| `add_tech_bonus` без `uses` | `{ bonus = 0.5 category = CAT_inf }` | по умолчанию 1, не баг; писать `uses = 1` явно для читаемости. Сейчас 6 в Казахстане |
| Несуществующая категория доктрины | `special_forces_doctrine` | сверять с категориями мода |
| Скрытая идея без tooltip | см. п.2 | добавить `custom_effect_tooltip` |
| Вода и филлеры в описании | "improve reliability and efficiency" | заменить конкретикой, см. `focus-loc.md`, п.8 |
| Пустая обёртка `OR = { NOT = { ... } }` с одним условием | `bypass` у `KAZ_naval_coop_russia` в старом коде | одно условие без обёртки |
| `country_exists` и в `available`, и в `bypass` | оба партнёрских фокуса флота Казахстана | оставить в `bypass`, в `available` только война и другие игровые условия |
| Промежуточное событие «запрос отправлен» перед ответом партнёра | `kaz_army.16` и `kaz_army.20` | удалить: событие шлётся партнёру сразу из фокуса (`design-guide.md`, п. 3.3) |
| Свой ключ `*_tooltip_loc` для эффекта, который стандартно показывает `effect_tooltip` | `KAZ_naval_russia_tooltip_loc` | `effect_if_they_accept_TT` + `effect_tooltip`; кастомный tooltip только для вариантов техники и случаев, когда иначе не показать |
| Иконка выбрана по названию, а не по использованию | `turk_naval` оказалась иконкой спора о газе у Израиля (`ISR_claim_aphrodite`) | перед выбором иконки смотреть, где она уже стоит: `grep -B3 "icon = ИМЯ" common/national_focus/*.txt`; корабельной иконки Турции в репозитории нет, взята `align_to_turkey` |
| Заглавные слова в id фокуса | `KAZ_First_Shipyards`, `KAZ_Naval_Cooperation_with_CHI` | `KAZ_first_shipyards`; страны словами, не тегами |
| Блок пустых строк между фокусами и фокус без названия-комментария | 21 пустая строка перед `KAZ_choose_new_doctrine` | `\t#English Name` вместо пустой строки перед `focus = {` |
| Осиротевшие `#`-заголовки от удалённых событий | `#USA Joint Exercises` и ещё три строки подряд, а событий под ними нет | при удалении события удалять и его заголовок; на одно событие один заголовок (`#Naval Cooperation with Turkey`), без дублирующих `#Event for ...` |
| Заголовок события «#TUR Accepted» и `ai_chance` в событии согласия с одним вариантом | `kaz_army.18`, `kaz_army.22` | `# TUR ... agreed`, без `ai_chance` (см. `event-loc.md`, раздел про заголовки) |
| Здание вручную: `random_owned_controlled_state` + `add_building_construction` + `treasury_change` | `KAZ_first_shipyards` | `N = { two_state_dockyards = yes }` (казна списывается скриптом) |
| Описание противоречит награде или пересказывает её списком | «two dockyards» против одного дока; «add a dockyard and cut the cost of the next naval doctrine» | факт, намерение, короткое последствие, без перечня бонусов; см. `focus-loc.md`, п. 2 и последний абзац |
| Выдуманное «реальное» сотрудничество | Китай и флот Казахстана | искать подтверждение; в тексте только проверенное (п. 4) |

## 4. Историческая достоверность (Казахстан, подтверждается ручным фактчеком)

- KMC "Астана Моторс" - гражданская компания, не ставить её в военный ремонт или модернизацию танков.
- 22-я бригада ГРУ СССР (Капчагай) перешла Казахстану после 1991: не называть "казахстанский ГРУ".
- Airbus Helicopters Kazakhstan Engineering (AHKE) уже существует (СП с Airbus): фокус "расширение", не "создание".
- Реформа округов 2003: округа стали региональными командованиями. Контрактная армия: план 99%, реально около 65%.
- Флот Казахстана (поиск 2026-10, проверять источник перед вставкой в текст): ВМС созданы указом 2003 года, главная база Актау; пограничная служба отдельно (Баутино, Атырау); в 1993 году досталась примерно четверть патрульных катеров Каспийской флотилии; подлодок нет. Завод «Зенит» стоит в Уральске на реке Урал, то есть не на побережье, корабли достраивают на Каспии. Тральщик «Алатау» (2016) построила российская верфь. Турция: соглашение «Зенита» с ASFAT и YDA о проектировании и постройке кораблей (2023), план верфи у порта Курык (2024) [?], обучение казахстанских кадетов. Южная Корея: катера типа Chamsuri и исследовательское судно, около 2006. Германия: меморандум с Abeking & Rasmussen о корветах (2016), не исполнен.
- Китай и флот Казахстана: подтверждены только заявка на постройку корабля (Eurasianet, год не указан) и коммерческие контейнерные хабы CSIC (2023). Военно-морского сотрудничества нет; Конвенция о статусе Каспия 2018 года запрещает присутствие вооружённых сил нерегиональных стран (знаю по памяти, не перепроверено).
- Правила: без гражданских компаний в военных фокусах без подтверждения; без хардкода столиц и имён лидеров; без спойлеров поздних фокусов. Факты из этого списка не проверялись здесь заново: перед тем как вставить в текст, проверить источник.

## 5. Чек-лист перед коммитом (объединённый)

- [ ] Описание обычно 200-280 знаков; допустимый диапазон 150-340. Формула факт → намерение → последствие — подсказка, не обязательный шаблон.
- [ ] Нет воды, афоризмов и конструкций "not just X, but Y".
- [ ] Начало отличается от соседних фокусов; нет повторов слов в абзаце.
- [ ] `log` первым в `completion_reward` и совпадает с id.
- [ ] Скрытые духи показаны (`defined_text` + tooltip).
- [ ] Нет дублей `swap_ideas` и повторов модификаторов между духами.
- [ ] Исторические факты проверены источником.
- [ ] У события есть подходящий `picture`, если доступен тематичный GFX; отсутствие картинки допустимо.
- [ ] Временный GFX помечен `#TODO`; не использовать случайную картинку ради заполнения поля.
- [ ] Событие согласия с одним вариантом не содержит лишний `ai_chance`.
- [ ] Дип-фокус: событие партнёру одной строкой из награды, `effect_if_they_accept_TT` + `effect_tooltip`, `bypass` одним `NOT`, без `country_exists` в `available`.
- [ ] Описание названо каждую награду (опыт, слоты, технология), ничего сверх награды.
- [ ] Нет несуществующих модификаторов и категорий.
- [ ] `python3 -I skills/tdf-country-content/scripts/tdf_audit.py .` не прибавил ERROR.
