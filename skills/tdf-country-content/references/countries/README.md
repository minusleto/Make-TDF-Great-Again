# Country style cards

Краткие карточки контекста для стран, представленных в TDF/MDC. Они помогают не повторять уже использованные сюжеты и находить уместные примеры, но не являются стандартами качества, полными аудитами или историческими справочниками.

## Как загружать

1. Прочитать общий `skills/tdf-country-content/SKILL.md`.
2. По текущему тегу открыть **одну** соответствующую карточку из списка ниже.
3. Открывать общие references только по задаче (код, локализация, события, решения, MIO и т. д.).

Не загружать все карточки при обычной работе. Если карточки ещё нет, использовать актуальные файлы страны и не заполнять пробелы стереотипами.

## Уровень проверки

- Срез репозитория: `main` на 2026-11-24, commit [26a6d8c](https://github.com/minusleto/Make-TDF-Great-Again/commit/26a6d8ca1f21fdaabbe7ca1c9294401727c1c165).
- Проверяемые ссылки на конкретные ID ведут к файлам в этом снимке.
- Высокая уверенность означает, что ID/тема присутствуют в локальном файле. Интерпретация стиля — редакторское наблюдение. Карточки не подтверждают историческую точность и не заменяют проверку актуальных внешних источников.
- Блок «Куда смотреть дальше» содержит идеи для исследования, а не утверждение, что темы отсутствуют в дереве. Перед созданием нового фокуса, события или механики повторно искать тему по всему актуальному контенту страны.
