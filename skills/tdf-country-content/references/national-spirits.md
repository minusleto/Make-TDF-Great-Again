# Нацдухи (национальные духи, ideas)

Источник: `mdredux/common/ideas/*.txt` (9 файлов, 2120 идей) и то, как их читают фокусы, решения, события и scripted loc. Цифры - автоматический подсчёт по тексту, ориентиры. Подсчёт модификаторов считает пары `ключ = число` в блоке `modifier`, поэтому вложенные блоки и `equipment_bonus` могут слегка искажать.

## 1. Что такое нацдух в ТДФ: четыре роли

| Роль | Что делает | Пример в репозитории |
|---|---|---|
| **Модификатор** | Пачка статичных бонусов за фокус | `POR_fiscal_discipline_idea`: два модификатора на стоимость соцрасходов и здравоохранения |
| **Дух-ключ** | Сам почти ничего не даёт, но от него зависят `visible`/`available` решений и события | `SOV_rjd_idea` открывает пакет решений РЖД; других таких ключей у России 66 |
| **Дух-хаб (состояние страны)** | Набор ступенчатых скрытых духов, которые игрок видит одной сводной подсказкой | `POR_portuguese_economy_idea` + `POR_last_centurys_infrastructure` / `...1`, `POR_brain_drain` / `...1` и т. д. |
| **Проблема с выходом** | Минус, который фокус или решение снимает или смягчает | `POR_chronic_underfunding_idea` снимается фокусом `POR_modern_army` |

Позиция по философии: нацдух хорош, когда он создаёт инструмент (ключ, хаб, проблема с выходом). Нацдух из одних бонусов - приправа к фокусу.

## 3. Правила

1. **Один дух - один профиль.** Модификаторы подходят названию и фокусу, который его выдаёт, и не повторяются в соседних позитивных духах. Мера: 3-5 модификаторов, капстоун до 6.
2. **Не выдавать бонус дважды.** Если фокус даёт технологический бонус, дух не дублирует его; если событие даёт казну, фокус не даёт её же.
3. **Ступени.** Улучшение - вторая идея с `name = <база>` и суффиксом `1` (`POR_professional_army_idea` 0.02 -> `POR_professional_army1_idea` 0.05). Один ключ loc обслуживает все ступени. Меняется через `swap_ideas = { remove_idea = X add_idea = X1 }`.
4. **Проблема должна иметь выход.** У Португалии: `POR_chronic_underfunding_idea` (минус 20% к скорости арсеналов и верфей и т. д.) снимается `remove_ideas` в фокусе реформы армии. Минус без выхода - ловушка, а не механика.
5. **Условие `cancel`.** Идея, привязанная к политическому режиму, получает `cancel`: `POR_fiscal_discipline_idea` пропадает, если у власти нет социал-демократов (`western_social_democrats_are_not_in_power = yes`). Для идей, которые должны пережить гражданскую войну, нужно `allowed_civil_war = { always = yes }` (у Португалии стоит почти везде).
6. **Скрытый дух обязан быть виден.** `hidden_ideas` невидимы: показывать через `defined_text` (trigger `has_idea`, ключ `X_loc1`), которую вызывает один tooltip-ключ. Порядок в сводном tooltip фиксирован.
7. **Один tooltip-ключ на все ступени**, цвета и формат единые.
8. **Реальные плюсы и минусы.** Не использовать `custom_modifier_tooltip` вместо настоящих модификаторов, если можно задать настоящий.

## 4. Дух-хаб: как собран `POR_portuguese_economy_idea`

1. Идеи-проблемы лежат в `hidden_ideas`: `POR_last_centurys_infrastructure`, `POR_brain_drain`, `POR_narcos_idea`, `POR_regional_development_gap`, `POR_energy_dependency`; у каждой может быть улучшенная ступень (`...1`) или ряд ступеней (`POR_narcos0_idea`, `POR_narcos1_idea`, `POR_narcos2_idea`).
2. `99_POR_scripted_localisation.txt`: на каждую проблему свой `defined_text` с условиями `has_idea = X` -> `localization_key = X_loc1`, при улучшении -> `X_loc2`.
3. В loc каждый ключ `X_loc1` - готовый блок с модификаторами в формате:
```
POR_brain_drain_loc1: "\n§gBRAIN DRAIN§!: \n$MODIFIER_GLOBAL_MONTHLY_POPULATION$: §R-10.00%§!\n$stability_factor$: §R-5.00%§!\n..."
```
Зелёный §G для плюса, красный §R для минуса, `$modifier$` вместо жёсткого английского.
4. Один видимый дух с `custom_modifier_tooltip` или фокус-tooltip `POR_portuguese_economy_tt` собирает все `[X_loc]` подряд.

Минусы паттерна: цифры в `X_loc1` дублируют значения из ideas вручную и расходятся, когда правят одно из двух. Правило: менять число в обоих файлах и проверять, что итог сходится.

## 5. Цифры (ориентиры из `md-hoi4-country-content/references/balance.md`)

- Модификаторов на дух: Португалия 4.3, Россия 4.5, Сирия около 4.3, Польша 5.3. Цель 3-5.
- Суша (медианы): `army_attack` 0.03-0.05, `army_defence` 0.05, `army_org` 0.035, `army_speed` 0.05, `experience_gain_army` 0.03, `training_time_army` минус 0.10, `supply_consumption` минус 0.07, `max_command_power` 9.
- Ступени у Португалии: профессиональная армия - первая ступень 0.02-0.04, вторая 0.05-0.07; экономия на соцрасходах -0.05 и -0.10 (плюс -0.05 к инфляции от долга на второй ступени).
- Выбросы (Польша: бонус к технологиям 1.5, PP 350) не использовать как норму.

## 6. Чек-лист на новый дух

- [ ] Название совпадает с профилем и с фокусом.
- [ ] 3-5 модификаторов, нет повтора в соседних духах и в награде фокуса.
- [ ] Есть выход, если это проблема.
- [ ] Для режимных духов задан `cancel`; для переживающих гражданскую войну - `allowed_civil_war`.
- [ ] Скрытый дух показан через `defined_text`; ключи `X`, `X_desc` и `X_loc1..N` есть и уникальны.
- [ ] Префикс страны правильный (`POL_` в словацких фокусах - баг).
- [ ] Если дух - ключ, указано, какое решение или событие его читает.
