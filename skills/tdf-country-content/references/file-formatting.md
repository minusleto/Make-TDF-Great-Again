# Форматирование файлов TDF/MDC

Единственный источник физических соглашений форматирования. Семантика focus/event/decision/idea и редакторский стиль описаны в соответствующих references.

## .txt и HOI4 script

- **[REQUIRED — соглашение проекта]** Новые и редактируемые блоки оформлять табами. В соседнем нетронутом legacy-коде сохранять имеющиеся пробелы/табы и окончания строк; не нормализовать файл целиком.
- **[REQUIRED — соглашение проекта]** Перед новым или редактируемым focus-блоком ставить короткий английский комментарий #English Focus Name с фактическим английским названием, когда оно доступно. Комментарий занимает место разделителя: сразу после закрывающей скобки предыдущего блока, без пустой строки до и после него.
- Если перед focus уже есть подходящий комментарий, исправить его, а не добавлять второй. Не добавлять комментарии массово в нетронутые legacy-блоки.
- Не выполнять массовую нормализацию или форматирование несвязанных участков только ради единообразия.

## English localisation YML

- **[REQUIRED — соглашение проекта]** Сохранять UTF-8 с BOM и заголовок l_english: без отступа.
- Ключи располагать с одним пробелом отступа; сохранять принятый синтаксис key:0 "text" в существующих файлах. Не добавлять/удалять суффикс :0 по собственной инициативе.
- Использовать экранирование кавычек и 
 для перевода строки внутри значения.
- Сохранять исходные окончания строк (обычно CRLF); точечно менять нужные ключи, не пересобирать весь YML.
- **[REQUIRED — соглашение проекта]** Ключи должны быть уникальны в доступном наборе локализации. Перед переименованием/удалением проверить все ссылки и overrides.
- Заголовок и структура key families остаются доменной темой соответствующего focus/event/decision/idea reference.

## newline = yes

- **[REQUIRED — решение команды]** Не добавлять newline = yes к focus или effect по собственной инициативе и не копировать его как шаблон legacy-кода. Использовать только по прямой просьбе пользователя либо при наличии конкретного подтверждённого требования проекта.
- Это не общее обязательное поле HOI4 focus/effect.

## Приоритет локального контекста

[REQUIRED] Для точечной правки следовать существующему формату соседнего блока и менять только нужный участок. Если старый блок отличается от современных соглашений, не переписывать его целиком без отдельного запроса.
