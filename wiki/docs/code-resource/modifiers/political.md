<a id="vanilla"></a>
## Ванильные

<a id="political-power"></a>
### Политическая власть

| Модификатор | Описание |
|---|---|
| `political_power_gain` | Дневной прирост политической власти |
| `political_power_factor` | Дневной прирост политической власти (%) |
| `political_power_cost` | Дневная трата политической власти |

<a id="stability"></a>
### Стабильность

| Модификатор | Описание |
|---|---|
| `stability_factor` | Меняет стабильность |
| `stability_weekly` | Еженедельный прирост стабильности |
| `stability_weekly_factor` | Еженедельный прирост стабильности (%) |
| `party_popularity_stability_factor` | Стабильность от популярности правящей партии |

<a id="ideology"></a>
### Идеология

| Модификатор | Описание |
|---|---|
| `drift_defence_factor` | Сопротивление идеологическому дрейфу |
| `communism_drift` | Ежедневный дрейф к реакционерам |
| `democratic_drift` | Ежедневный дрейф к прозападной линии |
| `fascism_drift` | Ежедневный дрейф к салафитам |
| `neutrality_drift` | Ежедневный дрейф к нейтралам |
| `nationalist_drift` | Ежедневный дрейф к националистам |
| `communism_acceptance` | Принятие курса реакционеров |
| `democratic_acceptance` | Принятие прозападного курса |
| `fascism_acceptance` | Принятие курса салафитов |
| `neutrality_acceptance` | Принятие курса нейтралов |
| `nationalist_acceptance` | Принятие курса националистов |

### Популярность партий
