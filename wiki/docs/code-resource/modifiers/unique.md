## Уникальные модификаторы

Это модификаторы, которые технически можно прописать где угодно, но реально они работают только для конкретных стран/континентов — потому что завязаны на механику, которая существует только там. Например, `literacy_rate_education_modifier` действует только для стран Африки, где вообще есть механика грамотности; `eng_lords_support_modifier` и похожие — только для Британии, где есть механика парламента (лорды/палата общин/заднескамеечники). Связанные эффекты — в [Уникальные (эффекты)](../../effects/unique/).

<a id="britain"></a>
### Британия

| Модификатор | Описание | Примечание |
|---|---|---|
| `eng_lords_support_modifier` | Ежемесячное изменение поддержки Палаты лордов | Только для Британии |
| `eng_commons_support_modifier` | Ежемесячное изменение поддержки оппозиции (Палата общин) | Только для Британии |
| `eng_backbenchers_support_modifier` | Ежемесячное изменение поддержки заднескамеечников | Только для Британии |

<a id="africa"></a>
### Африка

| Модификатор | Описание | Примечание |
|---|---|---|
| `literacy_rate_education_modifier` | Базовый прирост грамотности населения от образования | Только для стран Африки с механикой грамотности |
