## Космические модификаторы

Меняют скорость производства спутников и связанной с ними техники.

| Модификатор | Описание | Примечание |
|---|---|---|
| `spysat_production_speed_modifier` | Скорость производства спутника-шпиона | Н/Д |
| `comsat_production_speed_modifier` | Скорость производства спутника связи | Н/Д |
| `gnss_production_speed_modifier` | Скорость производства навигационного спутника | Н/Д |
| `killsat_production_speed_modifier` | Скорость производства спутника-перехватчика (ПКО) | Н/Д |
| `olv_production_speed_modifier` | Скорость производства ракеты-носителя | Н/Д |
