## Региональные модификаторы

Модификаторы, которые действуют на уровне конкретного региона (state), а не всей страны. Сначала — ванильные модификаторы игры, ниже — модификаторы MDC, разделённые по тем же категориям, что и обычные модификаторы.

<a id="vanilla"></a>
### Ванильные (база игры)

| Модификатор | Описание | Примечание |
|---|---|---|
| `local_building_slots` | Стартовое число общих слотов построек в регионе | Задаётся категорией региона, целое число |
| `local_building_slots_factor` | То же самое, в процентах | Н/Д |
| `resistance_growth` | Меняет скорость роста сопротивления в регионе | Н/Д |
| `recruitable_population_factor` | Меняет долю населения региона, доступную для набора | Н/Д |
| `air_defence` | Меняет силу ПВО региона | Задаётся зданием ПВО |
| `attrition` | Меняет истощение войск | Обычно страновой, но применим и в регионе/провинции |
| `state_resource_<ресурс>` | Меняет добычу конкретного ресурса в регионе (напр. `state_resource_steel`) | Подтверждено офиц. документацией модификаторов Paradox |
| `state_resources_factor` | То же самое для всех ресурсов региона, в процентах | Н/Д |
| `temporary_state_resource_<ресурс>` | Временно меняет добычу ресурса в регионе | Снимается отдельно, не постоянный |

<a id="economic"></a>
### Экономические

| Модификатор | Описание | Примечание |
|---|---|---|
| `state_productivity_growth_modifier` | Рост производительности на уровне региона | Н/Д |
| `state_monthly_population` | Ежемесячный прирост населения в конкретном регионе | Н/Д |

<a id="energy"></a>
### Энергетические

| Модификатор | Описание | Примечание |
|---|---|---|
| `state_renewable_energy_generation_modifier` | Меняет объём возобн. энергии в регионе | Н/Д |
| `state_renewable_capacity_factor_modifier` | Меняет коэффициент мощности возобновляемой энергетики в регионе | Н/Д |
