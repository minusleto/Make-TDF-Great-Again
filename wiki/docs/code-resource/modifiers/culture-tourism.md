# Культура и туризм

## Модификаторы

| Модификатор | Действие | Единица |
|---|---|---|
| `state_tourism_modifier` | Модификатор туризма в регионе | % |
| `country_tourism_modifier` | Модификатор туризма в стране | % |
| `state_culture_modifier` | Модификатор культуры в регионе | количество культуры |
| `country_culture_modifier` | Модификатор культуры в стране | количество культуры |
| `culture_defence_modifier` | Защита от культуры | % |
| `tourism_workers_modifier` | Модификатор работников в туризме | % |
| `tourism_productivity_modifier` | Модификатор продуктивности туристической отрасли | % |
| `tourism_tax_modifier` | Модификатор налогов туристической отрасли | % |

> Область действия и точные правила расчёта указаны по предоставленному описанию MDC. Если нужно, позже дополним примерами применения модификаторов в блоках `modifier = { ... }`.
