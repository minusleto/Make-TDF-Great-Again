---
title: Картели
description: "Скриптовые триггеры системы наркокартелей MDC."
---

Всего 2 триггера — сама система картелей (сила, влияние) описана в [Эффекты → Картели](../../effects/unique/#cartels).

```
has_cartels_penalties = yes
```
Есть активный штраф-модификатор `cartel_penalties` (`has_dynamic_modifier`) **и** страна ещё не победила картели (нет флага `CARTEL_defeated_the_cartels`).

```
is_cartel_nation = yes
```
Страна входит в список тегов, для которых вообще доступна система картелей — два региона:

- **Латинская Америка**: ARG, BLZ, BOL, BRA, CHL, COL, COS, ECU, ELS, GUA, GUY, HON, MEX, NIC, PAN, PAR, PRU, SUR, URG, VEN
- **АСЕАН**: BRM, BRU, LAO, MAY, PHI, SIA, VIE, SIN

Проверка идёт по `original_tag` — то есть учитывается исторический тег страны, а не текущий (например, если тег сменился через объединение или переименование, картели всё равно останутся привязаны к изначальной стране).
