## Голосующие блоки партий

Определяют, к какому идеологическому лагерю относится правящая партия страны для целей голосования в ЕС (соответствие номерам партий — как в [таблице субидеологий](../../systems/politics/#subideologies)):

| Триггер | Партии (по номеру) |
|---|---|
| `is_liberal_block` | 2 (Либералы), 16 (Либертарианцы) |
| `is_conservative_block` | 1 (Консерваторы), 6 (Реакционеры), 14 (Неприсоединившиеся консерваторы) |
| `is_communist_block` | 4 (Коммунисты), 5 (Левый радикализм), 19 (Неприсоединившиеся коммунисты) |
| `is_socialist_block` | 3 (Социал-демократы), 18 (Социалистические демократы) |
| `is_fascist_block` | 20 (Правые популисты), 21 (Фашисты), 22 (Военные), 23 (Монархисты) |
| `is_autocratic_block` | 0 (Прозападные автократы), 7 (Автократы), 13 (Неприсоединившиеся автократы), 15 (Олигархи) |

<a id="euroscepticism"></a>
## Евроскептицизм и Eurexit

`gov_is_eurosceptical` и `gov_is_EUexiteer` проверяют переменную `eurosceptic` (0–1) правящей страны, но порог зависит от идеологического блока правящей партии — левые/правые радикалы и центристы менее толерантны к евроинтеграции, чем условные центристские блоки:

| Блок (правящая партия) | Порог «евроскептик» | Порог «за Eurexit» |
|---|---|---|
| Консерваторы (1, 6, 14) | ≥ 0.5 | ≥ 0.6 |
| Либералы (2, 16) | ≥ 0.6 | ≥ 0.7 |
| Социал-демократы/зелёные (3, 17, 18) | ≥ 0.6 | ≥ 0.7 |
| Коммунисты (4, 5, 19) | ≥ 0.6 | ≥ 0.7 |
| **Националисты (20–23)** | **не требуется** — всегда да | **не требуется** — всегда да |
| Все остальные | ≥ 0.5 | ≥ 0.6 |

Националистический блок (20–23) — единственный, где переменная `eurosceptic` вообще не проверяется: считается евроскептиком/сторонником выхода из ЕС безусловно, независимо от значения переменной.

`slowdown_european_integration` — общий AI-триггер (для ai_will_do фокусов): срабатывает, если глобальная переменная `var_europeanism` < 0.85 ИЛИ хотя бы один член ЕС имеет `eurosceptic` > 0.45.

<a id="influence"></a>
## Внешнее и внутреннее влияние

**Внешнее влияние великих держав на страну** (обычно используется, чтобы решить, «отваливается» ли страна от ЕС в орбиту Китая или России-СССР):

| Триггер | Условие |
|---|---|
| `THIS_is_top3_influencer` / `FROM_is_top3_influencer` | THIS/FROM входит в топ-3 самых влиятельных стран для скоупа |
| `EU_external_chi_influence_50` / `_15` / `_10` / `_5` | Китай (CHI) — один из двух главных влияющих, с силой влияния выше 50/15/10/5% |
| `EU_external_sov_influence_50` / `_15` / `_10` / `_5` | То же самое для тега SOV (постсоветская держава) |
| `EU_external_sov_chi_influence_50` / `_15` / `_10` / `_5` | Китай **или** SOV превышают порог (либо страна вообще не член ЕС) |

**Собственное влияние страны на весь блок ЕС** — используется для лидерства во внешней/торговой политике и ратификации:

| Триггер | Условие |
|---|---|
| `influence_on_all_other_EU_members_3_percent` | Влияние >2.999% на каждого члена ЕС (кроме себя) |
| `influence_on_all_other_EU_members_5_percent` | То же, порог >5% (через хелпер `influence_higher_5`) |
| `influence_on_all_other_EU_members_10/20/25/30/50_percent` | Аналогично для соответствующих порогов |

<a id="offices"></a>
## Руководящие посты ЕС

Приоритет должностей выстроен в цепочку — если основная вакантна, роль переходит к следующей:

| Триггер | Логика |
|---|---|
| `is_leader_of_EU_foreign_policy` | Есть `EU_foreign_minister` → иначе `EU_commission_president` (если пост министра иностранных дел никем не занят) → иначе `EU_parliament_president` (если и пост главы Еврокомиссии никем не занят) |
| `is_leader_of_EU_trade_policy` | Аналогично: `EU_commission_president` → `EU_council_president` → `EU_parliament_president` |
| `any_EU_nation_holds_council_president` | Хоть один член ЕС занимает пост главы Совета ЕС |
| `any_EU_nation_holds_ECB_president` | Хоть один член ЕС занимает пост главы ЕЦБ |
| `influence_on_leader_of_EU_foreign_policy_25_percent` | У лидера внешней политики ЕС кто-то (или сама страна) имеет влияние >25% |
| `influence_on_leader_of_EU_trade_policy_25_percent` | То же для лидера торговой политики |

**Ратификация** (`EU_ratify_international_treaty`, `EU_ratify_trade_agreement`) — составные триггеры: договор считается ратифицированным, если у страны либо самой влияние >5% на весь блок, либо она возглавляет внешнюю/торговую политику ЕС **и одновременно** имеет влияние >5% (или >3% как более слабый второй вариант) на остальных членов.

<a id="membership"></a>
## Членство и институты

| Триггер | Описание |
|---|---|
| `is_EU_potential` | Тег входит в список ~60 европейских тегов-кандидатов, которые вообще способны быть частью системы ЕС (статичный список, не текущие члены) |
| `has_EU_external_border` | Член ЕС, у которого **нет** ни одного соседа — члена ЕС |
| `has_EU_external_home_border` | Член ЕС, у которого есть регион в домашней области, граничащий с не-членом ЕС |
| `EU_all_player_or_majors_hold_office` | Все члены ЕС, управляемые игроком (или все с >5% населения блока), занимают хоть один из 10 постов ЕС (Еврокомиссия, Совет, МИД, Европарламент, ЕЦБ, минфин, Frontex, евроармия/евронавы, посол в СБ ООН) |
| `EU_does_not_hold_another_office` | Страна не занимает никакой из этих 10 постов и недавно не покидала пост (флаг `recently_retired_from_an_eu_office`) |
| `EU_has_over_five_percent_pop` | Доля населения страны от общего населения ЕС >5% |
| `is_USoE_member` | Страна была аннексирована в «Соединённые Штаты Европы» (флаг `USoE_member`, тег более не существует) |
| `USoE_can_ally` | ROOT либо не состоит ни в одной военной фракции, либо возглавляет свою фракцию |
| `EU_ongoing_budget_draft_trigger` / `EU_ongoing_mff_draft_trigger` | Идёт голосование по проекту годового бюджета / многолетней финансовой рамки (MFF) |
| `EU_european_union_offices_trigger`, `..._euro_parliament_trigger`, `..._euro_info_trigger`, `..._council_voting_trigger`, `..._euro_fiscal_trigger` | Служебные UI-триггеры показа соответствующего экрана ЕС (флаг экрана + либо только что открытое меню ЕС, либо ИИ) |

<a id="regional-blocs"></a>
## Региональные блоки внутри ЕС

Используются в триггерах доктрины президента Европейской Федерации (POTEF). У каждого географического блока два варианта — `EU_member_is_X` (в блоке есть хоть один член ЕС) и `POTEF_is_X` (сам президент/кандидат — из этого блока):

| Блок | Страны |
|---|---|
| Альпийский | AUS, SWI |
| Бенилюкс | BEL, HOL, LUX |
| Иберийский | CAT, CNR, GAL, NAV, POR, SPA, SPR |
| Британский | ENG, IRE, SCO, WAS |
| Скандинавский | DEN, FIN, GRL, ICE, NOR, SWE |
| Средиземноморский | CRE, CYP, GRE, ITA, MLT, SCL |
| Балканский, Черноморский, Кавказский, Вишеградский, Балтийский, Восточный | (аналогичная структура; полный список стран — в исходнике) |

Плюс отдельно `POTEF_is_german` и `POTEF_is_french` (без парного `EU_member_is_` варианта — Германия и Франция проверяются напрямую по тегу).

<a id="majority-vote"></a>
## Подсчёт голосов (выборы президента ЕФ)

| Триггер | Логика |
|---|---|
| `absolute_majority_member_states` | Лидер гонки набрал больше голосов стран-членов, чем половина от общего числа членов ЕС |
| `absolute_majority_popular_vote` | Лидер гонки набрал больше половины голосов по общему числу (по населению) |
| `relative_majority_member_states` / `relative_majority_popular_vote` | Просто определяют лидера гонки (без проверки на 50%) |
| `EU_european_union_currently_exists` | В массиве `global.EU_member` есть хотя бы один член (ЕС не распущен) |

<a id="focus-votes"></a>
## Голосования по фокусам (`focus_EUxxx_accepted` / `_EP_approval`)

Для каждого фокуса из фокус-дерева ЕС в моде заведена пара служебных триггеров:

- `focus_EUxxx_accepted` — решение по этому фокусу принято (либо страна не член ЕС и правило её не касается, либо стоит флаг `focus_EUxxx_yes`/`focus_EUxxx_QMV_yes`)
- `focus_EUxxx_EP_approval` — Европарламент одобрил (глобальный флаг `focus_EUxxx_EP_approval`)

Такая пара есть для 49 фокусов: `focus_EU101`, `focus_EU102`, `focus_EU103`, `focus_EU104`, `focus_EU105`, `focus_EU110`, `focus_EU111`, `focus_EU112`, `focus_EU201`, `focus_EU202`, `focus_EU203`, `focus_EU204`, `focus_EU205`, `focus_EU206`, `focus_EU207`, `focus_EU208`, `focus_EU301`, `focus_EU302`, `focus_EU303`, `focus_EU304`, `focus_EU305`, `focus_EU306`, `focus_EU307`, `focus_EU308`, `focus_EU401`, `focus_EU402`, `focus_EU403`, `focus_EU404`, `focus_EU405`, `focus_EU406`, `focus_EU407`, `focus_EU408`, `focus_EU601`, `focus_EU602`, `focus_EU603`, `focus_EU605`, `focus_EU606`, `focus_EU607`, `focus_EU608`, `focus_EU609`, `focus_EU610`, `focus_EU611`, `focus_EU650`, `focus_EU651`, `focus_EU652`, `focus_EU653`, `focus_EU703`, `focus_EU998`, `focus_EU999`.

Так как смысл зависит от конкретного фокуса в дереве, а не от общей механики, расписывать каждый по отдельности здесь не имеет смысла — ищите нужный ID по номеру фокуса в дереве.
