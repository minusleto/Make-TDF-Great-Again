Большинство триггеров на этой странице по названию начинаются с `ai_`/`AI_` — это триггеры, которыми ИИ оценивает своё экономическое состояние (нужен ли долг, поднимать ли налоги и т.д.). Технически это обычные триггеры, их можно использовать где угодно (фокусы, решения, эффекты) — префикс `ai_` не накладывает никаких ограничений, это просто соглашение об именовании из исходников.

## ВВП и ВВП на душу населения

Для проверок в фокусах можно напрямую сравнивать переменные `gdp_total` и `gdp_per_capita` через `check_variable`. Готовые тултипы ниже предназначены для отображения понятного требования игроку вместе с текущим значением.

### ВВП на душу населения

Все эти тултипы показывают требование «больше чем N тыс. GDP на душу населения» и текущее значение `[?ROOT.gdp_per_capita]`:

| Тултип | Порог |
|---|---:|
| `2_per_capita_or_more_tt` | > 2k |
| `5_per_capita_or_more_tt` | > 5k |
| `10_per_capita_or_more_tt` | > 10k |
| `15_per_capita_or_more_tt` | > 15k |
| `20_per_capita_or_more_tt` | > 20k |
| `25_per_capita_or_more_tt` | > 25k |
| `30_per_capita_or_more_tt` | > 30k |
| `40_per_capita_or_more_tt` | > 40k |

Пример использования в `available`:

```txt
available = {
    custom_trigger_tooltip = {
        tooltip = 2_per_capita_or_more_tt
        check_variable = { gdp_per_capita > 1.999 }
    }
}
```

Для этих проверок в исходниках используется значение чуть ниже целого порога (например, `1.999` для 2k), чтобы условие фактически означало достижение соответствующего уровня.

### Общий ВВП

Тултипы для общего ВВП показывают требование «больше чем N млрд. Total GDP» и текущее значение `[?ROOT.gdp_total|3]`:

| Тултип | Порог |
|---|---:|
| `50_total_gdp_tt` | > 50b |
| `100_total_gdp_tt` | > 100b |
| `200_total_gdp_tt` | > 200b |
| `300_total_gdp_tt` | > 300b |
| `500_total_gdp_tt` | > 500b |
| `1000_total_gdp_tt` | > 1000b |
| `2000_total_gdp_tt` | > 2000b |
| `4000_total_gdp_tt` | > 4000b |
| `7000_total_gdp_tt` | > 7000b |

Пример использования:

```txt
available = {
    custom_trigger_tooltip = {
        tooltip = 200_total_gdp_tt
        check_variable = { gdp_total > 200 }
    }
}
```

Здесь `gdp_total` проверяется напрямую в миллиардах, а тултип отдельно показывает игроку требуемый порог и текущее значение.

## Казна

```
has_available_treasury = yes
```

Проверяет, есть ли у страны свободные деньги: если ВВП (`gdp_total`) больше 100 — нужно, чтобы `treasury > 10`; если меньше — достаточно, чтобы `treasury > debt` (казна больше долга).

### Низкая / высокая казна относительно уровня жизни

`ai_has_low_treasury` и `ai_has_high_treasury` — сравнивают `treasury` с порогом, который зависит от `gdp_per_capita` (чем богаче страна на душу населения, тем выше порог):

| `gdp_per_capita` | Низкая казна (`treasury <`) | Высокая казна (`treasury >`) |
|---|---|---|
| > 200 | 175.0 | 800.0 |
| 140–200 | 124.6 | 560.0 |
| 90–140 | 78.75 | 360.0 |
| 50–90 | 58.1 | 200.0 |
| 20–30 | 35.0 | 80.0 |
| 15–20 | 26.25 | 60.0 |
| 10–15 | 17.5 | 40.0 |
| 7–10 | 24.5 | 28.0 |
| 4–7 | 14.0 | 16.0 |
| 2–4 | 7.0 | 8.0 |
| < 2 | 3.5 | 4.0 |

:::caution
В исходнике одна вилка (`gdp_per_capita` от 20 до 30) продублирована дважды с одинаковыми условиями (`< 30` и `> 29.999`, затем ещё раз `< 30` и `> 19.999`) — это не ошибка в доке, а особенность исходного кода; в таблице выше показан рабочий результат.
:::

## Ставка ЦБ

```
ai_has_high_interest = yes
ai_has_low_interest = yes
```

`interest_rate > 3.50` / `interest_rate < 2.00`. Помечены в исходнике как *deprecated* («ставка должна восприниматься одинаково независимо от формы правления») — оставлены для обратной совместимости, для новых проверок лучше использовать `ai_has_minor/moderate/major_economic_problems` ниже, где порог уже адаптирован под конкретную ситуацию.

## Налоги (зависят от идеологии у власти)

Пороги зависят от того, какой из 4 идеологических блоков [из «Политики»](./political/#идеологические-блоки-по-кластеру-взглядов) у власти (национализм/салафизм в эту логику не включены — порогов для них в исходнике нет).

### Подоходный налог (`population_tax_rate`)

| Триггер | Коммунисты | Социалисты | Либералы | Консерваторы |
|---|---|---|---|---|
| `AI_has_high_population_taxes` | > 44 | > 39 | > 29 | > 24 |
| `AI_has_moderate_population_taxes` | 35–44 | 29–39 | 15–29 | 10–24 |
| `AI_has_low_population_taxes` | < 35 | < 30 | < 16 | < 11 |

### Налог на прибыль (`corporate_tax_rate`)

| Триггер | Коммунисты | Социалисты | Либералы | Консерваторы |
|---|---|---|---|---|
| `ai_has_high_corporate_taxes` | > 35 | > 25 | > 20 | > 15 |
| `ai_has_medium_corporate_taxes` | 19–36 | > 25¹ | > 20¹ | > 15¹ |
| `ai_has_low_corporate_taxes` | < 20 | < 15 | < 10 | < 5 |

¹ Для социалистов/либералов/консерваторов условие «средних» налогов в исходнике буквально совпадает с условием «высоких» (баг копипаста) — не пытайтесь найти скрытый смысл, это так и есть в файле.

## Баланс бюджета

`treasury_rate` — темп изменения казны (условно «% ВВП в неделю/месяц»).

### Общие пороги

| Триггер | Условие |
|---|---|
| `ai_has_deficit` | `treasury_rate < -0.05` |
| `ai_has_high_deficit` | `treasury_rate < -3.00` |
| `ai_has_surplus` | `treasury_rate > 0.05` |
| `ai_has_high_surplus` | `treasury_rate > 10.00` |

### «Приемлемый» дефицит/профицит по идеологии

| Триггер | Коммунисты | Социалисты | Либералы | Консерваторы |
|---|---|---|---|---|
| `ai_has_acceptable_deficit` | > −7.50 | > −6.75 | > −5.50 | > −3.00 |
| `ai_has_acceptable_surplus` | > 1.00 | > 2.00 | > 2.75 | > 3.50 |

### «Приемлемый» дефицит/профицит по числу фабрик

Чем больше `num_of_factories`, тем шире допустимый разброс `treasury_rate`:

| Фабрик | Деф. допустим (`treasury_rate >`, при этом `< 0`) | Профицит норма (`treasury_rate >`) |
|---|---|---|
| < 15 | −0.35 | 0.35 |
| 15–29 | −1.00 | 0.60 |
| 30–44 | −1.50 | 1.25 |
| 45–59 | −1.75 | 2.25 |
| 60–99 | −2.00 | 3.00 |
| 100–149 | −2.50 | 3.50 |
| 150–199 | −3.00 | 5.00 |
| ≥ 200 | −3.50 | 6.50 |

## Комплексные индикаторы «страна в беде»

`ai_has_minor_economic_problems` / `ai_has_moderate_economic_problems` / `ai_has_major_economic_problems` — совмещают высокую ставку ЦБ с дефицитом. Для США и Китая порог ставки ЦБ отдельный (ниже), т.к. их валюты резервные:

| Триггер | `interest_rate` (США/Китай) | `interest_rate` (остальные) | и одновременно `treasury_rate <` |
|---|---|---|---|
| `ai_has_minor_economic_problems` | > 0.6 | > 6.00 | −2.50 |
| `ai_has_moderate_economic_problems` | > 1.2 | > 8.999 | −5.00 |
| `ai_has_major_economic_problems` | > 1.999 | > 11.999 | −9.00 |

```
ai_economic_urgent_action = yes
```
`interest_rate < 18.00` **И** (`budget_array^6 > 40.00` **ИЛИ** `interest_rate > 10.00`) — «недельные расходы на процент по долгу съедают слишком много бюджета, но ситуация ещё не совсем безнадёжна».

## Долг к ВВП

`gdp_debt_ratio_lower_N` и `gdp_debt_ratio_higher_N` — набор порогов с шагом 5 от **5 до 200**: `gdp_debt_ratio_lower_5`, `gdp_debt_ratio_higher_5`, `gdp_debt_ratio_lower_10`, `gdp_debt_ratio_higher_10`, … вплоть до `_195`/`_200`. Итого 80 готовых триггеров.

```
gdp_debt_ratio_higher_60 = yes
```

## Экономические организации и блоки

Два разных триггера, оба сравнивают **два scope** (не текущую страну саму по себе), поэтому пишутся из `FROM`/`PREV`/`ROOT`:

```
ai_has_same_organization = yes       # FROM и THIS — сравнение с той страной, что вызвала эффект/триггер
in_same_economic_faction = yes       # PREV и THIS — сравнение с ранее сохранённым в scope государством
```

`ai_has_same_organization` (из `00_economic_triggers.txt`) проверяет членство в одной организации: НАТО, ЕС, Африканский союз, ECOWAS, ССАГПЗ, ШОС, Содружество наций.

:::caution
В исходнике блок «ASEAN» внутри `ai_has_same_organization` буквально скопирован из блока NATO (`has_idea = NATO_member` вместо `ASEAN_member`) — то есть проверки на ASEAN там **фактически нет**, это баг мода, а не доки.
:::

`in_same_economic_faction` (отдельный `MDDC_economic_faction_triggers.txt`) — более полный список блоков: ЕС, ГУАМ, АСЕАН, Лига арабских государств, ОАЕ, Африканский союз, ECOWAS, Содружество наций, СНГ, ЕАЭС, МЕРКОСУР, ССАГПЗ, БРИКС, АЛБА, USAID (только для США), ШОС, Вышеградская группа, «Инициатива трёх морей».
