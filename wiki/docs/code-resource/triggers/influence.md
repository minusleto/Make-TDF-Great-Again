## Как устроен массив влияния

У каждой страны есть `influence_array` (топ-7 стран, больше всего влияющих на неё, индекс 0 — самая влиятельная) и `influence_array_val` (процент влияния для каждого из этих 7 слотов). Почти все триггеры на этой странице — это разные способы спросить «эта страна входит в топ-N влияющих» и/или «её процент влияния выше/ниже X».

## Входит ли страна в топ влияющих

| Триггер | Условие |
|---|---|
| `is_influencer` | ROOT есть в `influence_array` (любой из 7 слотов) |
| `is_top_influencer` | ROOT — **самый** влиятельный (слот 0) |
| `not_is_top_influencer` | Инверсия предыдущего |
| `is_top3_influencer` | ROOT в топ-3 (слоты 0–2) |
| `is_top5_influencer` / `is_top5_influencer_ct`¹ | ROOT в топ-5 (слоты 0–4) |
| `is_top5_influencer_PREV` | То же самое, но проверяется `PREV`, а не `ROOT` |

¹ `is_top5_influencer` и `is_top5_influencer_ct` в исходнике **дословно одинаковы** (отличается только ключ тултипа) — используйте любой, они взаимозаменяемы.

## Топ влияния + порог процента одновременно

| Триггер | Условие |
|---|---|
| `is_top_twenty_influencer` | ROOT — топ-1 **и** его `influence_array_val^0 > 19.999` |
| `is_top_fifty_influencer` | ROOT — топ-1 **и** `> 49.999` |
| `is_top_eighty_influencer` | ROOT — топ-1 **и** `> 79.999` |
| `is_top3_twenty_influencer` | ROOT в топ-3, и именно в том слоте, где он стоит, процент `> 19.999` |
| `is_top3_thirty_influencer` | То же самое, но порог `> 29.999` |
| `is_top3_thirty_influencer_var` | Тот же порог 30%, но вместо `ROOT` сравнивается сохранённая ранее переменная `temp_country` |

## Тот же тип правительства (по 5 идеологическим тегам)

Все три триггера проверяют совпадение `has_government` (`democratic`/`nationalist`/`communism`/`neutrality`/`fascism`) у двух стран, но с разными парами scope:

| Триггер | Сравнивает |
|---|---|
| `is_same_government` | `ROOT` и текущий scope (`if/else_if` цепочка по 5 идеологиям) |
| `is_same_government_PREV` | `PREV` и текущий scope (через `OR`+`AND`, функционально то же самое) |
| `is_same_government_THIS_ROOT` | Явно `ROOT` и `THIS` (на случай, когда нужно не полагаться на «текущий» scope) |

## Порог влияния конкретной страны на эту

Три семейства, отличаются только тем, **чьё** влияние измеряется и в какую сторону сравнение:

```
influence_higher_30 = yes        # влияние ROOT на THIS выше 30%
sender_influence_higher_30 = yes # влияние FROM на THIS выше 30%
influence_less_30 = yes          # влияние ROOT на THIS ниже 30%
```

Готовые пороги (не равномерный шаг — ровно то, что есть в исходнике):

| Семейство | Доступные пороги |
|---|---|
| `influence_higher_N` | 5, 10, 15, 20, 25, 30, 35, 40, 50, 60, 70, 75, 80, 90 |
| `sender_influence_higher_N` | 5, 10, 15, 20, 25, 30, 40, 50, 60, 70, 80, 90 (без 35 и 75) |
| `influence_less_N` | 10, 20, 30, 40, 50, 60, 70, 80, 90 (только с шагом 10) |

`influence_less_N` устроен через цепочку `if/else_if` по всем 7 слотам массива (ищет, в каком именно слоте стоит ROOT, и сравнивает процент именно там) — если страны нет в `influence_array` вообще, триггер не сработает ни на одном из веток.

## Торговое соглашение

```
has_trade_agreement_with_PREV_nation = yes
```

Проверяет страновой флаг `trade_agreement@PREV` — есть ли действующее торговое соглашение с ранее сохранённой в scope страной.
