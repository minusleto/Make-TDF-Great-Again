Триггеры — условия, которые проверяют состояние игры (в отличие от эффектов, которые его меняют). Общее понятие разобрано на странице [Getting Started → Triggers](../getting-started/triggers.md), здесь — подробный список по категориям.

## Разделы

- [Базовые](basic.md) — ванильные HOI4-триггеры для новичков (NOT/AND/OR, операторы сравнения, has_stability и т.д.)
- [Политические](political.md) — партии у власти/в коалиции, идеологические блоки, пороги популярности
- [Экономические](economic.md) — казна, налоги, дефицит/профицит, долг к ВВП, экономические блоки
- [Военные](military.md) — пограничные конфликты, доктрины, сопротивление, ядерное оружие, медали, НАТО
- [Влияние](influence.md) — топ влиятельных стран, пороги процента влияния, торговые соглашения
- [Внутренние фракции](internal-factions.md) — уровни мнения (энтузиазм/враждебность) по каждой группе влияния
- [Евросоюз](eu.md) — влияние, руководящие посты, евроскептицизм, голосования
- [Регионы и провинции](regions.md) — исторические регионы, континенты, группы стран, Арктика
- [Культура и туризм](culture-tourism.md) — пороги культуры и условия стоимости решений
- [Картели](cartels.md) — штраф-модификатор картелей и список стран, где доступна система
