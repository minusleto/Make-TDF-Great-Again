Триггеры — условия, которые проверяют состояние игры (в отличие от эффектов, которые его меняют). Общее понятие разобрано на странице [Getting Started → Triggers](../getting-started/triggers/), здесь — подробный список по категориям.

## Разделы

- [Базовые](./basic/) — ванильные HOI4-триггеры для новичков (NOT/AND/OR, операторы сравнения, has_stability и т.д.)
- [Политические](./political/) — партии у власти/в коалиции, идеологические блоки, пороги популярности
- [Экономические](./economic/) — казна, налоги, дефицит/профицит, долг к ВВП, экономические блоки
- [Военные](./military/) — пограничные конфликты, доктрины, сопротивление, ядерное оружие, медали, НАТО
- [Влияние](./influence/) — топ влиятельных стран, пороги процента влияния, торговые соглашения
- [Внутренние фракции](./internal-factions/) — уровни мнения (энтузиазм/враждебность) по каждой группе влияния
- [Евросоюз](./eu/) — влияние, руководящие посты, евроскептицизм, голосования
- [Регионы и провинции](./regions/) — исторические регионы, континенты, группы стран, Арктика
- [Культура и туризм](./culture-tourism/) — пороги культуры и условия стоимости решений
- [Картели](./cartels/) — штраф-модификатор картелей и список стран, где доступна система
