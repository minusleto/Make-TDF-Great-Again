# Культура и туризм

## Скриптовые триггеры культуры

Эти триггеры проверяют порог культуры:

```text
has_50_culture = yes
has_100_culture = yes
```

В текущем описании указаны пороги 50 и 100 культуры. Если понадобятся другие значения, можно добавить дополнительные триггеры по тому же принципу.

## Проверка культуры в стоимости решения

Для решений можно проверять количество культуры через `custom_cost_trigger`, а текст стоимости задавать через `custom_cost_text`:

```text
custom_cost_trigger = {
    check_variable = { culture > 99 }
}
custom_cost_text = culture_100_0
```

Условие требует, чтобы переменная `culture` была больше 99; текст стоимости решения задаётся ключом `culture_100_0`.
