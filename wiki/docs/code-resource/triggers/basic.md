Эта страница — не про MDC-специфичные триггеры (те см. в разделах ниже, например [Политика](./political/)), а про то, как вообще устроены триггеры в движке HOI4 (Clausewitz). Если уже писал моды — можно пропускать.

## Что такое триггер-блок

Триггер — это проверка условия, которая возвращает «да» или «нет». Внутри `if`, `limit`, `trigger`, `available` и подобных блоков движок проверяет весь список условий и требует, чтобы **все** они были истинны:

```
trigger = {
	is_in_array = { ruling_party = 2 }
	has_war = no
}
```

Это равносильно «партия 2 у власти **И** страна не воюет» — несколько условий подряд в одном блоке уже работают как `AND`, отдельно писать `AND = { }` почти никогда не нужно (разве что для явной группировки внутри `OR`/`NOT`).

## Логические операторы

| Оператор | Что делает | Пример |
|---|---|---|
| `AND` | Все условия внутри должны быть истинны (по умолчанию и так работает, `AND = {}` пишут редко, для явной группировки) | `AND = { has_war = yes tag = GER }` |
| `OR` | Достаточно **одного** истинного условия внутри | `OR = { tag = GER tag = ITA }` |
| `NOT` | Инвертирует **всё**, что внутри блока (если внутри несколько условий — они сначала объединяются через AND, а потом весь результат инвертируется) | `NOT = { has_war = yes }` — «не воюет» |
| `NAND`, `NOR` | Отдельных ключевых слов нет — то же самое через `NOT = { AND = {...} }` / `NOT = { OR = {...} }` | `NOT = { OR = { tag = GER tag = ITA } }` — «не Германия и не Италия» |

:::caution
Частая ошибка новичков: `NOT = { tag = GER tag = ITA }` — это **не** «не Германия и не Италия», а «не (Германия И Италия)» = «страна не является одновременно и тем, и другим», что истинно почти всегда. Для «ни то, ни другое» нужен именно `NOT = { OR = { ... } }`.
:::

## Операторы сравнения

Для чисел (стабильность, военная поддержка, свои переменные и т.д.) движок понимает стандартные математические операторы. Работают они по-разному в зависимости от того, встроенное это значение или переменная:

**Встроенные игровые значения** — оператор пишется прямо рядом с триггером:

```
has_stability > 0.5
has_war_support < 0.3
num_of_factories = 20
```

**Собственные переменные (`set_variable`/`set_temp_variable`)** — нужен `check_variable` с оператором внутри:

```
check_variable = { my_custom_var > 10 }
check_variable = { party_pop_array^2 = party_popularity@democratic }
```

Доступные операторы: `>` больше, `<` меньше, `=` равно (для чисел — не путать с присваиванием, тут это именно «равно»), `>=` больше или равно, `<=` меньше или равно.

## Частые ванильные триггеры

Небольшая шпаргалка того, что встречается почти в каждом файле мода:

| Триггер | Проверяет | Пример |
|---|---|---|
| `has_stability` | Уровень стабильности страны (0–1) | `has_stability > 0.6` |
| `has_war_support` | Уровень военной поддержки (0–1) | `has_war_support < 0.4` |
| `has_government` | Идеологию у власти | `has_government = communism` |
| `has_idea` | Есть ли у страны конкретная идея/бонус | `has_idea = oligarchs` |
| `has_country_flag` | Установлен ли страновой флаг (скриптовая метка) | `has_country_flag = some_event_happened` |
| `is_in_array` | Есть ли индекс/значение в конкретном массиве страны | `is_in_array = { ruling_party = 2 }` |
| `tag` / `original_tag` | Текущий/стартовый тег страны | `tag = GER` |
| `exists` | Существует ли страна с таким тегом (жива, не аннексирована) | `exists = FRA` |
| `is_puppet` | Является ли страна чьим-то марионеточным субъектом | `is_puppet = yes` |
| `has_war` | Воюет ли страна (в любой войне) | `has_war = yes` |
| `date` | Сравнение с игровой датой | `date > 1950.1.1` |

Полный список ванильных триггеров — в официальной [вики HOI4 modding](https://hoi4.paradoxwikis.com/Triggers), здесь только то, что реально часто нужно в контексте MDC.

## custom_trigger_tooltip

Почти все MDC-триггеры (см. [Политика](./political/) и другие разделы) завёрнуты в `custom_trigger_tooltip` — это не логика, а просто способ показать игроку читаемую подсказку вместо серого технического текста:

```
custom_trigger_tooltip = {
	tooltip = my_readable_tooltip_key
	has_stability > 0.5
}
```

Для игрока в тултипе появится текст по ключу `my_readable_tooltip_key` (берётся из файла локализации) вместо стандартного «Stability is greater than 50%». На саму логику проверки это не влияет — это чисто про подсказки в интерфейсе.
