## Архетипы оборудования

| Токен | Расшифровка |
|---|---|
| `Inf_equipment` | Пехотное стрелковое снаряжение |
| `infantry_weapons` | Базовое стрелковое оружие пехоты (архетип) |
| `AA_Equipment` | Зенитное вооружение (ПВО) |
| `H_AT_Equipment` | Тяжёлое противотанковое вооружение (ПТУР, безоткатные орудия) |
| `L_AT_Equipment` | Лёгкое противотанковое вооружение (РПГ) |
| `sam_missile_equipment` | Зенитные управляемые ракеты (ЗРК) |
| `anti_ship_missile_equipment` | Противокорабельные ракеты |
| `guided_missile_equipment` | Управляемые ракеты (общая категория) |
| `ballistic_missile_equipment` | Баллистические ракеты |
| `nuclear_missile_equipment` | Ракеты с ядерной боевой частью |
| `nuclear_ballistic_missile_equipment` | Баллистические ракеты с ядерной боевой частью |
| `hypersonic_missile_equipment` | Гиперзвуковые ракеты |
| `command_control_equipment` | Оборудование командования и управления (C2) |
| `cnc_equipment` | Оборудование командования и управления (C2), доп. категория |
| `cross_river_equipment` | Понтонно-переправочное оборудование |
| `train_equipment` | Железнодорожный подвижной состав |
| `util_vehicle_equipment` | Вспомогательная колёсная техника (грузовики, джипы) |
