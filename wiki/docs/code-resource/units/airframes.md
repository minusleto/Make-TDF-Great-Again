## Расшифровка

- `small_plane` — лёгкий самолёт · `medium_plane` — средний самолёт · `large_plane` — тяжёлый самолёт
- `cv_` — палубный (carrier-based, для авианосцев)
- `cas` — штурмовик (Close Air Support) · `awacs` — ДРЛО · `scout` — разведчик · `strike` — ударный · `suicide` — БПЛА-камикадзе
