## Расшифровка префиксов

- `L_` — лёгкий · `Mot_` — моторизованный · `Mech_` — механизированный · `Arm_` — бронированный
- `armor_` — танковый · `SP_` — самоходный · `HQ_` — штаб подразделения
- `Bat` — батальон · `Comp` — рота · `Battery` — батарея
- `Air_Inf` — аэромобильная пехота · `Recce` — разведка · `Arty` — артиллерия · `R_Arty` — реактивная артиллерия
