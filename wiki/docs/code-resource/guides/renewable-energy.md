## Гидроэлектростанции и геотермальная энергетика

Чтобы добавить региону дополнительную мощность ГЭС, геотермальной или "hotspot"-возобновляемой энергетики, нужно задать пару переменных и подключить динамик-модификатор.

- **`hydroelectric_energy_production_var`** — средняя выработка мощности (в ГВт) всей гидроэнергетической инфраструктуры региона. Если у вас есть данные в годовых ТВт·ч — переведите их в средний ГВт.
- **`hydroelectric_energy_storage_var`** — ёмкость хранения (в ГВт·ч). Получается делением годовых ТВт·ч на 8.760 (часов в году, в тысячах), чтобы получить среднюю мощность в ГВт.

```txt
set_variable = { hydroelectric_energy_production_var = 5.636 }
set_variable = { hydroelectric_energy_storage_var = 300 }
add_dynamic_modifier = { modifier = hydroelectric_infrastructure_in_state }
```

Та же схема работает и для геотермальной энергетики (примеры готовой настройки — в регионах Италии).

## Капасити-фактор возобновляемой энергии

Для возобновляемой энергии (не гидро/гео) капасити-фактор региона берётся из [Global Wind Atlas](https://globalwindatlas.info/en), поле **"Capacity Factor - IEC Class I"**. Найдите на карте нужный регион и наведите курсор — значение появится в правом нижнем углу.

Формула:

```
Капасити-фактор = значение с Atlas − 0.25
```

:::caution
В исходном источнике этого гайда пример на словах не совпадает с формулой: там написано "Atlas 0.80 → капасити-фактор 0.50", хотя по формуле 0.80 − 0.25 = **0.55**. При этом код-пример ниже использует именно `0.55` — похоже, в текстовом описании просто опечатка, а не в самой формуле. Ориентируйтесь на формулу и код-пример, не на число "0.50" в прозе.
:::

Задаётся статическим модификатором региона при старте игры:

```txt
set_variable = { state_renewable_capacity_factor_modifier_var = 0.55 }
```
