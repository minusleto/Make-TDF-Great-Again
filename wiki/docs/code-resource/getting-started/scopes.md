## Что такое scope

Scope определяет, к какому объекту применяется текущий блок кода. В MDC особенно часто встречаются country, state и временные переходы между scope.

### Частые переходы

- `THIS` — текущий scope.
- `ROOT` — исходный scope верхнего уровня.
- `FROM` — scope, из которого пришёл переход.
- `PREV` — предыдущий scope.

> Всегда проверяйте фактический scope перед использованием эффекта или триггера: одинаковый код может работать по-разному в country/state/other scope.
