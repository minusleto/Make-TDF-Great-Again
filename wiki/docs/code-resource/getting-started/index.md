## С чего начать

Если вы впервые пишете код для MDC, начните с:

1. [Переменных](./variables/)
2. [Scope](./scopes/)
3. [Triggers](./triggers/)
4. [Скриптовых эффектов](../effects/)

## Важно

Названия эффектов, триггеров, модификаторов, переменных и путей к файлам в примерах должны оставаться в оригинальном виде — это код, а не локализация.
