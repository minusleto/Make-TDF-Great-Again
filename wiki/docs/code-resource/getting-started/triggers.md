## Что такое trigger

Trigger — условие, которое проверяет состояние игры. Triggers используются в `if`, `limit`, `trigger`, `available` и других блоках.

### Практическое правило

Сначала определите scope, затем проверяйте, существует ли нужный trigger именно для этого типа объекта. Не путайте trigger с effect: trigger проверяет состояние, effect изменяет его.
