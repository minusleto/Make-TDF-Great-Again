## Выдать бонус к исследованию технологий

Выдаёт стране **ограниченный по числу использований бонус к исследованию технологий**. Бонус можно привязать либо к конкретным технологиям через `technology`, либо к категории технологий через `category`.

### Параметры эффекта

| Параметр | Что делает |
|---|---|
| `name` | Имя бонуса, используемое в интерфейсе исследования. Необязательно. |
| `bonus` | Бонус к скорости исследования. `0.5` = +50% к исследованию при использовании бонуса, `1.0` = +100%. |
| `uses` | Сколько раз бонус можно использовать. Если `uses` не указан, бонус получает **1 использование**. |
| `ahead_reduction` | На сколько **лет** уменьшается штраф за исследование технологии раньше срока. `1` = уменьшить ahead-of-time штраф на 1 год, `2` = на 2 года. |
| `category` | Категория технологий, на которую распространяется бонус. Можно указать несколько категорий. |
| `technology` | Конкретная технология, на которую распространяется бонус. Можно указать несколько технологий. |

### Бонус для конкретных технологий

Если указать `technology`, бонус доступен только для перечисленных технологий:

```text
add_tech_bonus = {
    name = assembly_bonus
    bonus = 0.5
    uses = 2
    technology = improved_machine_tools
    technology = advanced_machine_tools
    technology = assembly_line_production
}
```

Здесь страна получает **2 использования бонуса +50%**, которые можно потратить на любые две из перечисленных технологий.

### Бонус для категории технологий

Вместо списка конкретных технологий можно указать `category`:

```text
add_tech_bonus = {
    name = electronics_bonus
    bonus = 0.5
    category = electronics
}
```

Поскольку `uses` не указан, этот бонус получает **1 использование**. Его можно потратить один раз на подходящую технологию из указанной категории.

### Снижение штрафа за исследование раньше срока

`ahead_reduction` — это не дополнительный процент скорости исследования. Он уменьшает **штраф за исследование технологии раньше её исторического срока** на указанное количество лет.

Например:

```text
add_tech_bonus = {
    name = early_electronics_bonus
    ahead_reduction = 2
    uses = 1
    category = electronics
}
```

Такой бонус позволяет одним использованием уменьшить ahead-of-time штраф подходящей технологии на **2 года**.

Если указаны и `bonus`, и `ahead_reduction`, они относятся к одному и тому же ограниченному исследовательскому бонусу:

```text
add_tech_bonus = {
    name = electronics_bonus
    bonus = 0.5
    ahead_reduction = 1
    uses = 1
    category = electronics
}
```

Одно использование можно потратить либо на **+50% к скорости исследования**, либо на **снижение ahead-of-time штрафа на 1 год**. Это не постоянные модификаторы страны.

### Бонус к исследованию и снижение штрафа вместе

Параметры можно указывать в одном `add_tech_bonus`. Они описывают **два типа преимущества одного исследовательского бонуса**, а не постоянные модификаторы страны.

```text
add_tech_bonus = {
    name = tank_development_bonus
    bonus = 1.0
    ahead_reduction = 1
    uses = 1
    category = armor
}
```

Здесь одно использование даёт либо **+100% к скорости исследования**, либо **снижение ahead-of-time штрафа на 1 год** для подходящей технологии.

## Ограничение бонуса: категория и технология

`category` выбирает группу технологий, а `technology` — конкретные технологии. Оба параметра могут использоваться для ограничения того, на что можно потратить бонус.
