## Разное

Ванильные эффекты HOI4, не относящиеся ни к одной конкретной механике мода — сюда попадает всё, для чего нет отдельной тематической страницы.

### Переименование провинции/региона

| Эффект | Скоуп | Описание |
|---|---|---|
| `set_province_name` | Любой (берёт `id` явно) | Переименовывает конкретную провинцию: `set_province_name = { id = 6332 name = "Новое имя" }` |
| `set_state_name` | **Только скоуп state** (без `id`) | Переименовывает регион, в чьём скоупе вызван: `5 = { set_state_name = "Новое имя" }` или `every_owned_state = { limit = {...} set_state_name = "Новое имя" }` |

Переименование навсегда сохраняется в сейве и работает в мультиплеере. Ни один ванильный/модовый файл при этом не перезаписывается.

⚠️ **Проверяйте `controls_state = X` в `available`/`limit` фокуса или ивента**, прежде чем вызывать `set_state_name` для конкретного региона. Без этой проверки можно переименовать регион, который вы фактически не контролируете (например, если фокус активировался до захвата региона или регион был потерян) — так лучше не делать.

### Переменные и утилиты

| Эффект/триггер | Описание |
|---|---|
| `clamp_variable` | Зажимает переменную между `min` и `max` (оба необязательны). Порядок применения — `Max(Min(var, max), min)`. Если `max < min`, в дебаг-режиме будет ошибка в лог |
| `random_list` | Выбирает случайный эффект из списка по весам (вес может быть переменной). `seed = var_name/const/random` — задать свой сид вместо сида скоупа |
| `is_in_array` | Проверяет, есть ли значение в массиве: `is_in_array = { array = имя_массива value = 42 }`, короткая форма — `is_in_array = { имя_массива = 42 }` |

```
clamp_variable = {
	var = num_dogs
	min = 0
	max = num_cats
}

random_list = {
	log = yes # включить лог броска кубика в game.log
	10 = { add_political_power = 10 }
	10 = { add_political_power = 100 }
}

is_in_array = { ruling_party = 12 }
```

### Тултипы и скрытые эффекты

| Эффект/триггер | Описание |
|---|---|
| `custom_trigger_tooltip` | Работает как `and`-триггер, но с кастомным текстом тултипа вместо автогенерируемого списка условий. Если триггер внутри `NOT = {...}`, сначала проверяется `KEY_NOT` вариант локализации |
| `custom_effect_tooltip` | Просто показывает кастомный текст тултипа, без логики условий |
| `hidden_effect` | Выполняет эффект, но не показывает его в тултипе игроку — используется для служебной логики (флаги, переменные), которую не нужно светить в интерфейсе |

### Динамические модификаторы

| Эффект/триггер | Описание |
|---|---|
| `add_dynamic_modifier` | Добавляет динамический модификатор стране/региону/командиру. Если он уже есть — обновляет кулдаун. `days` — сделать временным; `scope` — необязательно, применить к другой стране/региону/переменной со скоупом, а не к текущему |
| `has_dynamic_modifier` | Проверяет, есть ли у скоупа динамический модификатор (тот же параметр `scope`, если модификатор был нацелен на другой скоуп) |

```
add_dynamic_modifier = {
	modifier = my_dynamic_modifier_name
	days = 42
	scope = GER
}

has_dynamic_modifier = {
	modifier = my_dynamic_modifier_name
	scope = GER
}
```

### Косметические теги

| Эффект/триггер | Описание |
|---|---|
| `set_cosmetic_tag` | Задаёт стране косметический тег (влияет только на отображение — флаг, название и т.п., не меняет реальный тег страны): `INS = { set_cosmetic_tag = IN1 }` |
| `has_cosmetic_tag` | Проверяет, установлен ли у страны конкретный косметический тег: `INS = { has_cosmetic_tag = INS1 }` |

### Юниты и гражданские войны

| Эффект/триггер | Описание |
|---|---|
| `create_equipment_variant` | Создаёт новый вариант техники (например, класс корабля) на основе родительского типа — `parent_version`, `upgrades`, `modules` наследуются от родителя, если не переопределены явно |
| `division_template` | Добавляет стране шаблон дивизии |
| `has_civil_war` | Проверяет, участвует ли страна в гражданской войне — как мятежник (revolter) или как цель (target) |
| `original_tag` | Возвращает исходный тег страны — актуально при проверках в контексте гражданской войны, где текущий тег скоупа отличается от изначального |

### Владение и контроль региона

| Триггер | Описание |
|---|---|
| `controls_state` | Проверяет **фактического контролёра** региона (кто сейчас военным путём удерживает территорию) |
| `owns_state` | Проверяет **де-юре владельца** региона (кому регион принадлежит по праву, независимо от оккупации) |

Разница важна: оккупированный регион — `controls_state` у оккупанта, а `owns_state` всё ещё у исходного владельца. Именно поэтому мы предупреждали выше: для `set_state_name` нужна проверка `controls_state`, а не `owns_state` — переименовывать стоит то, чем реально управляешь прямо сейчас.

### Правительство и идеология

| Триггер | Описание |
|---|---|
| `has_government` | Проверяет, относится ли правящая партия страны к **идеологической группе** (democratic/communism/fascism/neutrality/nationalist), а не к конкретной субидеологии MDC — для проверки конкретной субидеологии используйте `ruling_party`/`is_in_array`, см. [«Как работают выборы и коалиции»](../guides/elections/) |
| `has_elections` | Проверяет, разрешены ли в стране выборы: `has_elections = yes` |
| `has_start_date` | Сравнивает начальную дату **текущей партии** (не текущую игровую дату) — полезно для ивентов, зависящих от того, с какого года вообще была начата игра |

### Лидеры и офицеры

| Эффект/триггер | Описание |
|---|---|
| `create_country_leader` | Создаёт лидера и добавляет его в нужную партию страны (полный синтаксис и примеры — в [гайде про субидеологии](../guides/subideologies/)) |
| `kill_country_leader` | Убивает лидера страны и полностью его удаляет — следующий по очереди в партии становится новым лидером |
| `create_corps_commander` | Создаёт командира корпуса для страны |
| `has_country_leader_with_trait` | Проверяет, есть ли у текущего лидера страны указанная черта: `has_country_leader_with_trait = big_fat_idiot` |

### Провинции, юниты и войска

| Эффект/триггер | Описание |
|---|---|
| `every_owned_state` | Выполняет вложенные эффекты для каждого своего региона, удовлетворяющего `limit` |
| `add_province_modifier` | Добавляет статические модификаторы конкретной провинции. Провинцию можно выбрать явно (`province = 500`) либо через фильтр: `all_provinces`, `limit_to_coastal`, `limit_to_border`, `limit_to_naval_base`, `limit_to_victory_point` |
| `create_unit` | Создаёт юнит вне OOB-файла (аналог обычного размещения при старте) — можно указать провинцию, приоритеты выбора провинции через `country_score`, запретить спавн на вражеской территории, дать `id` для последующего удаления |
| `num_of_factories` | Проверяет суммарное количество фабрик (гражданских+военных+верфей) |
| `add_tech_bonus` | Добавляет технологический бонус с ограниченным числом применений |

### Дипломатический статус

| Триггер | Описание |
|---|---|
| `is_in_faction` | Проверяет, состоит ли страна в какой-либо (военной) фракции |
| `is_puppet` | Проверяет, является ли страна чьей-либо марионеткой |
| `is_subject` | Проверяет, является ли страна чьим-либо субъектом (более широкая категория, чем просто марионетка — включает и другие типы подчинения) |
