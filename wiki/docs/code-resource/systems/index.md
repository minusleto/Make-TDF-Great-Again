## Системы

Здесь описаны игровые механики MDC, у которых нет отдельного скриптового API — только логика самой системы.

- [Политика](politics.md) — идеологии, коалиции, выборы и список слотов субидеологий
- [НАТО](nato.md) — статусы, путь вступления, решения, события и идеи альянса

Скриптовые эффекты и модификаторы систем экономики, влияния, внутренних фракций, энергетики, картелей, ЕС и терроризма (со стороны его сторонников) вынесены в раздел [Эффекты](../effects/index.md), так как именно там документируется весь их код.
