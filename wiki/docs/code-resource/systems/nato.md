НАТО (Организация Североатлантического договора) — военный союз коллективной обороны. Полное членство доступно только странам определённого региона (Европа, Кавказ, плюс явные исключения `CAN`/`USA`/`TUR`) — остальные могут претендовать только на статус **Major Non-NATO Ally** (см. ниже).

Главное на этой странице — **в каком порядке идут решения**, чтобы вступить в альянс. Не про то, что дают конкретные национальные духи (это отдельная тема).

## Путь к членству: 4 шага

Обычный путь состоит из 4 последовательных этапов. Каждый следующий шаг открывается только после завершения предыдущего.

### 1. PfP — Partnership for Peace

Решение: **`become_NATO_pfp_member`** · стоимость 100 PP.

Доступно странам нужного региона, у которых ещё нет статуса PfP/IPAP и нет членства. По завершении случайный член НАТО-лидер фракции получает событие `generic_nato.1` (решает, принять заявку или нет).

### 2. IPAP — Individual Partnership Action Plan

Три решения подряд:

1. **`GENERIC_nato_ipap_application_decision`** — подать заявку на IPAP. Требования: не состоять ни в какой фракции, суммарная added tension < 15, влияние СССР/Китая/Перу на вас не выше 10%, нет фракции военных (`has_idea = the_military`), военные расходы хотя бы на базовом уровне (не `defence_00/01/02`).
2. **`ratify_country_ipap`** — **каждый действующий член НАТО** по отдельности ратифицирует именно вашу заявку (решение с целью — `target_array = global.NATO_ipap_Candidates`), теряя 20 PP за голос.
3. **`GENERIC_nato_ipap_decision`** — доступно, когда **все** члены НАТО ратифицировали (`array = global.nato_members`, проверка по каждому). Даёт идею `GENERIC_nato_ipap_idea`, устанавливает военный доступ со всеми членами.

:::caution
Казахстан (`KAZ`) явно включён в список стран, которым доступны PfP и IPAP, но **не включён** в список для Accelerated Dialogue и Membership Action Plan (там только Европа/Кавказ/CAN/USA/TUR) — то есть застревает на втором из четырёх шагов и дальше продвинуться не может. Похоже на недосмотр в исходниках, а не задуманное ограничение.
:::

### 3. Accelerated Dialogue

Решение: **`GENERIC_nato_accelerated_dialogue_decision`**.

Требования те же, что для IPAP (низкое влияние СССР/Китая/Перу, нет фракции военных, есть базовые военные расходы), плюс уже должен быть статус IPAP. По завершении лидер НАТО-фракции получает событие `generic_nato.12`.

### 4. Membership Action Plan → ратификация → вступление

Три решения подряд:

1. **`finish_NATO_membership_action_plan`** · 100 PP — самый требовательный шаг. Помимо отсутствия войны и фракции: added tension < 10, нет фракции военных, военные расходы не на нуле, полиция не на минимуме (`NOT police_01`), и **нет активной серьёзной коррупции** (`paralyzing/crippling/rampant/unrestrained/systematic_corruption`).
2. **`ratify_country_accession`** — снова каждый член НАТО ратифицирует персонально (-20 PP за голос).
3. **`join_NATO`** — доступно, когда ратифицировали **все** члены. Даёт полное членство (`NATO_join`).

Если у страны `can_join_NATO = no` (не подходит по каким-то условиям на момент вступления), `NATO_join` вместо полного членства выдаёт `Major Non-NATO Ally`.

## Обходной путь: прямое приглашение

Параллельно долгой цепочке решений есть более быстрый путь через события — США могут напрямую пригласить страну, минуя все 4 шага:

**Заявка кандидата → США решают (`NATO.14`) → кандидат решает (`NATO.9`)**

- США соглашаются рассмотреть заявку почти всегда (AI-шанс отказа — 1 из 100), кандидат получает приглашение `NATO.9` через 6 часов.
- Если кандидат соглашается — сразу `NATO_join = yes`, минуя ратификации. AI охотнее соглашается на выборах или если это Вьетнам при существовании Китая; никогда не соглашается, если страна коммунистическая или субъект Китая.
- Прибалтийские/балканские страны (`EST/LAT/LIT/SLO/SLV/ROM/BUL/ALB/CRO`) по сценарию никогда не отказываются от приглашения.

## Major Non-NATO Ally

Альтернативный статус для стран **вне** региона полного членства (не Европа/Кавказ/CAN/USA/TUR/KAZ).

Решение **`NATO_apply_to_become_major_non_nato_ally`** · 100 PP. Требования: демократия, ВВП > 350, и либо высокое мнение (>100) лидера НАТО-фракции, либо просто хорошее мнение (>100) от любого члена массива `global.nato_members`. Не работает, если страна уже в фракции, уже имеет статус НАТО/ОДКБ, либо помечена как непризнанное государство/негосударственный актор.

Снимается решением **`denounce_Status_As_Major_Non_NATO_Ally`**.

## После вступления

Что доступно уже действующему члену — коротко, без деталей бонусов:

| Решение | Цена | Что делает |
|---|---|---|
| `leave_NATO` | 100 PP | Выход из НАТО |
| `NATO_ratify_stanag` | 250 PP | Ратификация стандарта STANAG (даёт идею с боевыми бонусами) |
| `start_military_exercises_with_NATO` | command power > 49 | Запускает событийную цепочку военных учений с союзником |
| `NATO_nrf_start` | 100 PP, только во время войны | Мобилизует Силы быстрого реагирования НАТО |
| `NATO_arf_start` | 50 PP, только во время войны | Мобилизует Союзнические силы быстрого реагирования |
| `NATO_joint_operation` | 125 PP | Просит остальных членов вступить в вашу войну |
| `demand_alliance_intervention` (для Major Non-NATO Ally) | 125 PP, нужен surrender progress > 0.7 | Просит альянс о военном вмешательстве |
| `NATO_ask_to_join_f35_program` | 50 PP | Заявка на участие в программе F-35 (для Major Non-NATO Ally) |

`leave_NATO` у ИИ по умолчанию почти никогда не срабатывает для демократий; для остальных идеологий и конкретных стран (Турция, Прибалтика, Греция, Италия, Дания, Испания и др.) в исходниках прописаны отдельные исключения — например, Турция остаётся в НАТО, если у власти национализм/коммунизм/фашизм или ПСР (`ruling_party = 12`) при нейтралитете.
